## 主要证据文件

- `landing.html`：高保真响应式首页原型，是颜色、排版、布局、组件和文案气质的主要来源
- `index.html`：原型入口页，提供次级入口视觉和简化 token 证据
- `critique.json`：原型批判结果，说明层级、品牌、动效和清晰度的设计判断
- `IMPLEMENTATION_PLAN.md`：源项目实施计划，帮助确认设计目标和交付范围

## 保留策略

- 保留原始页面源码副本到 `source_examples/`
- 从页面里抽出可复用 token 到 `colors_and_type.css`
- 将关键品牌图形重建到 `assets/` 和 `build/`
- 将页面级设计语言拆成 `preview/` 聚焦预览和 `ui_kits/app/` 应用化 kit

## 缺失证据

以下资产在复制证据中不存在，因此未伪造：
- 原生字体文件
- 品牌正式 SVG logo 源文件
- App 图标导出尺寸包
- 真实截图素材或照片素材

本工作区仅根据现有 HTML / CSS / SVG 证据重建了可复用设计资产，不臆造未提供的品牌物料。
